# Alimony claim — пакет «Стягнення аліментів»

Загальні правила інтерв'ю — у скілі `legal-intake`. Тут — знання пакета.

## Що це за документ

- «ПОЗОВНА ЗАЯВА про стягнення аліментів» (сервіс `alimony`) — на утримання дитини/дітей до повноліття.
- Подається **до суду за місцем проживання відповідача** (знайти суд: https://court.gov.ua/ — з шапки шаблону).
- Структура за шаблоном: шапка (суд → позивач → відповідач) → обставини (шлюб/стосунки, діти, з якої дати відповідач не утримує дитину) → обґрунтування → «ПРОШУ СУД» → Додатки → підпис.
- Підходить для будь-якого сімейного стану (`marital_status`: `married` / `divorced` / `never_married`) — «Від цього залежить формулювання у позові» (hint конфіга).

## Правова основа (РІВНО з alimony.citations.json)

- Сімейний кодекс України — ст. 141, 150, 180, 181, 182, 183, 184 — https://zakon.rada.gov.ua/laws/show/2947-14
- Цивільний процесуальний кодекс України — ст. 174, 175 — https://zakon.rada.gov.ua/laws/show/1618-15
- Закон України «Про судовий збір» — ст. 5 — https://zakon.rada.gov.ua/laws/show/3674-17

Статті у текст підставляє шаблон — НЕ додавай інших. За шаблоном позивач звільнений від судового збору на підставі п.3 ч.1 ст.5 Закону України «Про судовий збір».

## Що підготувати заздалегідь (з «Додатки» шаблону + hints)

- копія свідоцтва про укладення шлюбу — 2 прим. (якщо шлюб був зареєстрований);
- копія рішення суду про розірвання шлюбу — 2 прим. (якщо `marital_status == 'divorced'`; з нього — дата, суд, № справи, якщо відомі);
- копія свідоцтва(-в) про народження дитини (дітей) — по 2 прим. (дані йдуть у `children_details`);
- довідка про склад сім'ї — 2 прим. («Довідка підтверджує, що дитина проживає з вами» — hint; її дата = поле `family_cert_date`);
- копія паспорта позивача — 2 прим.;
- копія облікової картки платника податків (ІПН) позивача — 2 прим. (якщо позивач не відмовився від ІПН);
- 1 екземпляр позовної заяви з копіями доданих документів для відповідача.

## Форма стягнення (`alimony_type`): percent vs fixed

- Hint дослівно: «% від доходу — автоматично розраховується судом. Фіксована сума — зручна якщо дохід відповідача нерегулярний або невідомий.»
- `percent` («Частка від заробітку (1/4, 1/3 або 1/2)») — частку обчислює ДВИЖОК за кількістю дітей (helper `alimonyFraction`); шаблон додає «але не менше 50 відсотків прожиткового мінімуму для дитини відповідного віку». Грошових сум прожиткового мінімуму в системі НЕМАЄ — не називай цифр.
- `fixed` («Тверда грошова сума (фіксована)») → відкривається `alimony_fixed_amount` (грн/місяць; hint: «Вкажіть бажану суму. Не менше 50% прожиткового мінімуму для дитини.»).

## Формати ключових полів

- `children_details` (textarea, ОБОВ'ЯЗКОВЕ). Hint дослівно: «Кожна дитина — окремий рядок. Формат: ПІБ, дата народження, свідоцтво № ... від ...». Приклад із placeholder: `Іванов Олег Іванович, 15.05.2018, свідоцтво № І-КВ 123456 від 16.05.2018`. Дата всередині рядка — ДД.ММ.РРРР, як у прикладі (НЕ ISO).
- `defendant_position` — у РОДОВОМУ відмінку; hint дослівно: Вкажіть у родовому відмінку: «менеджера», «бухгалтера», «директора».
- Date-поля (`birth_date`, `family_cert_date`, `abandonment_date`, `alimony_start_date`, …) — як параметр інструмента завжди `YYYY-MM-DD`.
- `alimony_start_date` — hint: «Зазвичай — сьогоднішня дата. Аліменти стягуються починаючи з дати подачі позову.»
- `abandonment_date` — hint: «Вкажіть приблизну дату, з якої відповідач перестав надавати фінансову допомогу.»
- Рахунок для присуджених коштів (за шаблоном — частина сьома ст. 175 ЦПК): `plaintiff_has_account` → якщо true: `plaintiff_account_iban` (валідація IBAN) + `plaintiff_account_bank`; якщо ні: `plaintiff_payout_method` («Якщо рахунку немає — вкажіть, як бажаєте отримати присуджені кошти.»).

## Порядок інтерв'ю (config.tabs)

1. `plaintiff` — «Позивач»: ПІБ, дата народження, адреси, ІПН/паспорт, контакти, ЄСІТС, рахунок для коштів.
2. `defendant` — «Відповідач»: ПІБ, адреси, ІПН/паспорт, контакти, ЄСІТС.
3. `family` — «Шлюб і діти»: `marital_status`, дані шлюбу/розірвання (за станом), `children_details`, `family_cert_date`, `abandonment_date`.
4. `alimony` — «Аліменти»: `alimony_type` (+ сума при `fixed`), `alimony_start_date`, `defendant_employed` (`yes`/`no`/`unknown`) → місце роботи/посада/зарплата, інші доходи.

## Обов'язкові поля (required без show_if — 16)

`last_name`, `first_name`, `middle_name`, `birth_date`, `registered_address`, `defendant_last_name`, `defendant_first_name`, `defendant_middle_name`, `defendant_registered_address`, `marital_status`, `children_details`, `family_cert_date`, `abandonment_date`, `alimony_type`, `alimony_start_date`, `defendant_employed`.

Умовні поля відкриваються за show_if (передумови описані у схемі інструмента) — вимоги перевіряй через `validate_params`, не вгадуй.

## Що гарантує чеклист (alimony.checklist.json, fail-closed)

Перед видачею документа сервер перевіряє наявність у тексті:

- Обов'язок батьків утримувати дитину (ст. 180 СК);
- Пункт ПРОШУ СУД зі стягненням аліментів (фіксована сума або частка доходу);
- Розкриття судового збору (звільнення на підставі ЗСЗ);
- Блок підпису позивача.
