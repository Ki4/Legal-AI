## Як використовувати

1. Відкрий TWA форму через Telegram бот
2. Обери сценарій (рекомендую #4 для швидкого тесту, #2 для перевірки дітей/аліментів)
3. Заповнюй поля по табах: Позивач → Відповідач → Шлюб і сім'я → Провадження
4. Натисни "Надіслати"
5. Чекай повідомлення від бота з посиланням на Google Doc
