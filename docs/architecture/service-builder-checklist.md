# Service Builder — Чеклист для юриста

> Цей документ заповнює юрист перед зустріччю з розробником.
> На основі відповідей розробник створює: `form_config`, `document-builder.js`, `declension-prompt.txt`, `test-fixtures`.

## 2. Запитання до клієнта (form_config)

> Для кожного питання заповни таблицю. Питання стануть полями форми.

### Як заповнювати:
- **Тип**: текст / дата / так-ні / вибір з варіантів / кілька варіантів / textarea / телефон

- **Показувати якщо**: вказати умову (`залежить від поля X = значення Y`) або залишити пусто
- **Підказка**: короткий пояснювальний текст (з'являється за іконкою ?)

## 3. Шаблон документу (document builder)

> Напиши або вклей текст документу. Там де потрібно підставити дані з форми — використовуй `{{НАЗВА_ПОЛЯ}}`.
> Там де текст залежить від умови — позначай `[ЯКЩО умова: текст]`.

### Приклад:
```
До {{НАЗВА_СУДУ}}
від {{ПРІЗВИЩЕ_ІМ'Я_ПОБАТЬКОВІ_ПОЗИВАЧА}}, {{ДАТА_НАРОДЖЕННЯ}},
який(яка) проживає за адресою: {{АДРЕСА}}

ПОЗОВНА ЗАЯВА

[ЯКЩО є діти: Від шлюбу сторін народились спільні неповнолітні діти: {{ДІТИ_ПІБ_ДАТИ}}.]

Прошу суд:
1. Стягнути з відповідача аліменти у розмірі {{РОЗМІР_АЛІМЕНТІВ}} від доходу.
```

### Твій шаблон:
```
(вклей текст документу тут)
```

### Список плейсхолдерів:
> Перелічи всі `{{НАЗВА}}` які використав у шаблоні та яке поле форми їм відповідає.

| Плейсхолдер | Поле з форми (# з таблиці питань) | Потребує відмінювання? |
|-------------|-----------------------------------|------------------------|
| `{{ПРІЗВИЩЕ_ПОЗИВАЧА}}` | #1 | так (родовий, орудний) |
| `{{ДАТА_НАРОДЖЕННЯ}}` | #4 | ні |
| … | | |

## Для розробника (після зустрічі з юристом)

На основі заповненого чеклиста створити:
```
src/data/{service}FormConfig.ts          — form_config (з таблиці питань)
n8n-templates/{service}-document.js      — buildDocument(answers, ai)
prompts/{service}-declension-prompt.txt  — якщо потрібне відмінювання
test-data/{service}/fixtures/scenario-1..3.mjs
test-data/{service}/expected/scenario-1..3.txt
```

Оновити в Supabase:
```sql
INSERT INTO services (slug, title, form_config, ai_prompt, watched_laws)
VALUES ('{service}', '{Назва}', '{form_config JSON}', '{prompt}', '{laws JSON}');
```
