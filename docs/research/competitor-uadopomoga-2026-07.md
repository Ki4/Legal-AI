# Конкурентный разбор: UA Dopomoga (uadopomoga.eu)

**Дата:** 2026-07-16
**Кто исследовал:** обход всех публичных страниц (главная, /zzp, /accountant, /tax-refund, /specialists, /marketplace, /pricing, /guide, /journey, /about).
**Зачем:** прогрев рынка самозанятых украинцев + subscription-модель для «ФОП-аналога» → прямая калька на наш пивот medФОП (2k грн/міс).

## 1. Что это за продукт (в одном абзаце)

**UA Dopomoga** — «цифровая экосистема» для украинцев в Нидерландах. Позиционируется как «всё для жизни в NL в одном приложении»: документы, налоги, ZZP (=нидерландский ФОП/самозанятость), инвойсы, дедлайны, AI-помощник и маркетплейс проверенных специалистов. Основатели — сами украинцы, прошедшие адаптацию в 2022–23. 4 языка: UA / EN / NL / RU.

**Ключевой вывод:** это **не** информационный портал и **не** маркетплейс. Это **SaaS-подписка для самозанятых** (ZZP Pro), обёрнутая в бесплатное информационное ядро для привлечения трафика, плюс несколько разовых платных услуг. Маркетплейс — витрина «на будущее», сейчас **пустой**.

## 2. Монетизация — многослойная (это главное, что стоит забрать)

Они зарабатывают не одним способом, а «лесенкой» под разные сегменты одной аудитории:

| Продукт | Цена | Модель | Кому |
|---|---|---|---|
| **Free** | €0 навсегда | Freemium-магнит | всем (инфа, гайды, калькуляторы, просмотр маркетплейса) |
| **ZZP Pro** | **€49.99/мес** или €379/год (−37%) | Подписка SaaS | самозанятым (инвойсы, BTW, дедлайны, AI без лимитов) |
| **Возврат налогов «сам»** | €39 / год | Разовая | наёмным работникам |
| **Возврат налогов «бухгалтер подаёт»** | €89 / подача | Разовая | наёмным, «под ключ» |
| **+ Fiscaal partner** | +€20 / +€50 | Апселл | семьям |
| **Консультация бухгалтера** | €70/час (Pro — €35) | Разовая | всем |
| **Годовая декларация** | €169 | Разовая | ZZP |
| **Ведение ZZP** | €129/мес (Pro включён) | Retainer | ZZP «под ключ» |
| **Маркетплейс** | сейчас бесплатно | (будущее: Pro €9/мес для специалистов + featured boost) | специалистам |

**Уроки для нас:**
- **€49.99/мес ≈ 2 200 грн/міс** — это почти **точь-в-точь наш таргет 2 000 грн/міс** для medФОП. Внешняя валидация ценовой точки: за автоматизацию рутины самозанятый в ЕС платит ~€50/мес и это считается «за цену одного часа работы».
- Годовая подписка со скидкой −37% (€379) — стандартный приём снижения churn и предоплаты кэша.
- **Разовые услуги отдельно от подписки** — «оплатил → получил», не требуют подписки. Снижают барьер входа: человек, не готовый на €50/мес, платит €39 разово и попадает в воронку.
- Апселл-логика: Free → разовый возврат → ZZP Pro → «ведение под ключ» €129. Одна аудитория, четыре ценовых уровня.

## 3. AI-помощник — эмоциональный крючок №1

Вся коммуникация строится вокруг одного болевого сценария:
> «Пришло письмо из Belastingdienst (налоговой) — паника, непонятный нидерландский. AI объяснил за минуту на украинском и помог составить ответ + поставил дедлайн в календарь.»

- AI подаётся как: разбор официального письма → перевод → черновик ответа → следующий шаг + дедлайн.
- AI **не** подаёт документы за тебя и **не** заменяет бухгалтера — только объясняет и готовит.
- «Было → Стало»: хаос из 7 вкладок, Google Translate и Viber-групп → один спокойный кабинет.

**Урок:** продают не «фичи AI», а **снятие тревоги** перед государством/бюрократией на родном языке. Для medФОП аналог — тревога перед МОЗ/НАЗК/податковою, ліцензійними умовами, перевірками. Это тот же эмоциональный двигатель.

## 4. Human-in-the-Loop + юридическая осторожность (важно для нас)

Они очень аккуратно очерчивают, **чего НЕ делают** — и это осознанная стратегия де-рискинга:

- «Это **не** индивидуальная юридическая консультация — для конкретного случая нужен специалист.»
- «Мы **НЕ** представляем твои интересы в судах, госорганах или переговорах.»
- «Бухгалтерские услуги оказываare **сертифицированными партнёрами**. Dopomoga **не несёт ответственности** за налоговые решения; ответственность — за бухгалтером и клиентом.»
- Для чувствительного (подача декларации) — живой сертифицированный бухгалтер + официальный механизм **DigiD Machtigen** («пароль не передаёшь, доступ отозвать в любой момент»).

**Урок для нас:** они **сознательно избегают регулируемого поля** (юр. представительство, гарантия суммы возврата) и остаются в зоне «инфо + инструменты + свести с лицензированным специалистом». Наш продукт (генерация судебных документов) — **более рискованная зона**, чем у них. Их модель дисклеймеров + HITL + «сумму/результат не гарантируем, это делает госорган» — готовый шаблон юридической защиты, который стоит скопировать дословно.

- Заявлено 17+ категорий, фильтры (город, язык, цена, рейтинг, verified, Pro/Business) — полноценный UI построен, но **предложение = 0**.

**Урок (дорогой, бесплатно для нас):** двусторонний маркетплейс — тяжёлый cold-start. Они **построили весь UI маркетплейса, но не смогли его наполнить**, и в итоге **сдвинули фокус на SaaS-подписку (ZZP Pro) и разовые услуги**, которые не требуют критической массы поставщиков. About-страница всё ещё описывает старую стратегию («marketplace v1 сейчас, Pro €9/мес — фаза 2»), но реальный продукт уже про другое (ZZP Pro €49.99 продаётся сейчас). Видно, что **пивотнули с "маркетплейс-first" на "SaaS-first"**.

→ Для нас: **не вести с маркетплейса/каталога юристов**. Вести с инструмента, который создаёт ценность в одиночку (генерация документа / автоматизация рутины ФОП), где ценность не зависит от наличия второй стороны.
