## 2. Группировка в пакеты

**Пакет A — «Старт ФОП-лікар» (базовый, массовый сегмент).** Только требования
«для всех лицензиатов», без блока «заклад охорони здоров'я»: перелік засобів
вимірювальної техніки + наказ (№ 22), накази про уповноважених осіб (№ 24, 25),
наказ про контроль якості меддопомоги (№ 30, без медради), форми інформованої
згоди (№ 37), інструкції з дезінфекційних засобів (№ 44.4), пакет захисту
персональних даних (№ 49), комплект «куточок споживача» с переліком послуг
(№ 58), договір оренди приміщення (№ 59). Почему: минимальный обязательный
документарный слой для соло-ФОП без наёмных сотрудников; все позиции высокой
шаблонизируемости — идеально для полностью автоматической генерации из одной
анкеты.

**Пакет B — «Клініка ТОВ/ПП» (полный организационный).** Всё из пакета A плюс
блок пп. 1 п. 12 Ліцензійних умов и кадры: положення (статут) про заклад (№ 9),
положення про ВСП (№ 10), штатний розпис (№ 11), посадові інструкції (№ 12),
правила внутрішнього розпорядку (№ 13), клінічні маршрути (№ 14), положення про
медичну раду (№ 30), наказ + положення про ЛКК (№ 43.1), трудові договори і
накази про прийняття (№ 80), комплект форм первинної облікової документації за
спеціальностями (№ 28, 40). Почему: юрлица несут все обязанности ФОП плюс ~10
«заклад»-специфичных документов; естественный премиум-тир с большим средним
чеком.

**Пакет C — «Профильные надстройки» (аддоны к A/B, продаются модулями).**
Лаборатория: документи контролю якості досліджень (№ 26/55). Стационар: СОПи
профілактики внутрішньолікарняних інфекцій (№ 44.12), положення про відділ
інфекційного контролю (№ 44.11). Реабилитация: форма індивідуального
реабілітаційного плану (№ 53.1). Аренда оборудования: договір на використання
обладнання (№ 61). Почему: применимость условная — навешиваются на базовый пакет
вопросами анкеты («є лабораторія? стаціонар? реабілітація?»), не раздувая
базовую цену. Рентген (№ 44.13) в пакет не включать — низкая шаблонизируемость.

**Пакет D — «Lifecycle / события» (транзакционные разовые документы).**
Повідомлення до МОЗ про зміни (№ 27), заяви про зупинення/відновлення дії
ліцензії, відомості про усунення підстав, інформація про сплату штрафу
(№ 62–66), повідомлення про неможливість укласти трудові договори (№ 81).
Почему: нужны не при старте, а по событию — канал повторных продаж существующим
клиентам пакетов A/B; каждый документ прост и генерируется мгновенно.

## 3. Статистика чек-листа

- **Всего вопросов:** 84 пронумерованных (№ 1–84); 8 из них (№ 43, 44, 51, 53,
  54, 68, 69, 73) детализированы **45 подпунктами**. Проверяемых позиций со
  своей градацией риска — **122**. Колонка «ступінь ризику» в исходнике везде
  перечисляет все три варианта (Високий/Середній/Незначний) — это варианты для
  отметки проверяющим, фактический уровень риска в тексте не проставлен.
- **Документарных позиций** (требуется наличие документа, включены в каталог):
  **36 позиций** — около **30%** чек-листа. Из них высокая пригодность к
  шаблонизации — 24 позиции, средняя — 9, низкая — 3.
- **Недокументарных позиций:** ~86 — оборудование/помещения, вывеска, оплата,
  кадрово-квалификационные требования (дипломы/сертификаты — не генерируются),
  процессные требования (разрешённые методы, ЕСОЗ, санэпидрежим).
- **Применимость ФОП vs юрлица:** только для ЗОЗ/юрлиц — ~26 позиций;
  условно-профильных (лаборатория, рентген, реабилитация, стационар) — ~15;
  остальные ~80 распространяются на всех, включая ФОП. Практический вывод:
  документарная нагрузка соло-ФОП — 12–15 документов (пакет A), клиники-юрлица —
  25+ документов (пакет B), т.е. чек юрлица закономерно ~×2 при том же движке
  генерации.
