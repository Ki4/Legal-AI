# Кандидат: Військові спори (ТЦК / мобілізація / відстрочка)

**Статус:** исследованный кандидат, НЕ запланированная фича. Требует решения PM + поиска юриста-партнёра по военному праву.
**Scope:** ✅ в рамках `specs/mission.md` (прямо перечислены «військові спори»).

---

## 1. Спрос — почему кандидат №1

- Админсуды **перегружены** делами, связанными с мобилизацией: оскарження рішень ТЦК та СП, ВЛК, призову, відстрочки/бронювання, постанов про адмінправопорушення у сфері військового обліку. Источники: [PRAVO.UA](https://pravo.ua/perevantazhennia-administratyvnykh-sudiv-u-spravakh-pov-iazanykh-iz-mobilizatsiinymy-protseduramy-systemnyi-vyklyk-ta-potreba-v-dosudovykh-mekhanizmakh), [ЮРЛІГА — практика 2024-2025](https://jurliga.ligazakon.net/analitycs/236203_pokazova-sudova-praktika-u-sporakh-z-ttsk-ta-sp-u-2024---2025-rokakh).
- Драйверы: страх + жёсткая срочность → высокая готовность платить.
- **Конкурентная ниша пустая:** ни FastDoc, ни Legal Mind, ни Дія, ни нишевые генераторы документы по ТЦК НЕ делают.

## 2. Ключевой риск: доверил бы человек боту свою судьбу?

**Нет — в судебном бою против ТЦК человек заплатит адвокату.** Ставки экзистенциальные (свобода, фронт, жизнь), цена ошибки катастрофична. Бот не может быть «адвокатом в суде» здесь.

**Это перекраивает продукт, а не отменяет его.** Боту место ДО суда и на типовых действиях:
- **Tier 1 (автономно, низкий риск):** заява про відстрочку при однозначных основаниях (многодетность, уход за инвалидом, бронь), досудова скарга в ТЦК, информационный триаж «какие у вас основания / что делать дальше», сбор пакета документов.
- **Эскалация (high-stakes):** реальный адмінпозов / спор по ВЛК / оспаривание призыва → честная передача **юристу-партнёру по военному праву**.

## 3. Бизнес-модель — ОТЛИЧАЕТСЯ от развода/алиментов

| | Развод/алименты | Військові спори |
|---|---|---|
| Монетизация | продажа документа | **referral / комиссия с лида** + возможно дешёвый триаж-документ |
| Валидатор | Ольга (семейное право) | **нужен юрист по военному/админ праву** (не Ольга) |
| Tier | 1 | 1 (досудебное) + эскалация |
| Ценность высоких ставок | нейтрально | **повышает** ценность тёплого лида для адвоката |

## 4. Цена входа (почему дорого)

- Другой домен права (админ/военное), другой валидатор-партнёр.
- Обязательная честная эскалация и аккуратные дисклеймеры (юридическая ответственность выше).
- Риск репутации при overreach: если бот сгенерирует «уверенный» документ по проигрышному делу — вред человеку и бренду.
