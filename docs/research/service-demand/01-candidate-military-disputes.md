# Кандидат: Військові спори (ТЦК / мобілізація / відстрочка)

**Статус:** исследованный кандидат, НЕ запланированная фича. Требует решения PM + поиска юриста-партнёра по военному праву.
**Scope:** ✅ в рамках `specs/mission.md` (прямо перечислены «військові спори»).

---

## 1. Спрос — почему кандидат №1

- Админсуды **перегружены** делами, связанными с мобилизацией: оскарження рішень ТЦК та СП, ВЛК, призову, відстрочки/бронювання, постанов про адмінправопорушення у сфері військового обліку. Источники: [PRAVO.UA](https://pravo.ua/perevantazhennia-administratyvnykh-sudiv-u-spravakh-pov-iazanykh-iz-mobilizatsiinymy-protseduramy-systemnyi-vyklyk-ta-potreba-v-dosudovykh-mekhanizmakh), [ЮРЛІГА — практика 2024-2025](https://jurliga.ligazakon.net/analitycs/236203_pokazova-sudova-praktika-u-sporakh-z-ttsk-ta-sp-u-2024---2025-rokakh).
- Драйверы: страх + жёсткая срочность → высокая готовность платить.
- **Конкурентная ниша пустая:** ни FastDoc, ни Legal Mind, ни Дія, ни нишевые генераторы документы по ТЦК НЕ делают.

## 2. Ключевой риск: доверил бы человек боту свою судьбу?

**Нет — в судебном бою против ТЦК человек заплатит адвокату.** Ставки экзистенциальные (свобода, фронт, жизнь), цена ошибки катастрофична. Бот не может быть «адвокатом в суде» здесь.

**Это перекраивает продукт, а не отменяет его.** Боту место ДО суда и на типовых действиях:
- **Tier 1 (автономно, низкий риск):** заява про відстрочку при однозначных основаниях (многодетность, уход за инвалидом, бронь), досудова скарга в ТЦК, информационный триаж «какие у вас основания / что делать дальше», сбор пакета документов.
- **Эскалация (high-stakes):** реальный адмінпозов / спор по ВЛК / оспаривание призыва → честная передача **юристу-партнёру по военному праву**.

## 3. Бизнес-модель — ОТЛИЧАЕТСЯ от развода/алиментов

| | Развод/алименты | Військові спори |
|---|---|---|
| Монетизация | продажа документа | **referral / комиссия с лида** + возможно дешёвый триаж-документ |
| Валидатор | Ольга (семейное право) | **нужен юрист по военному/админ праву** (не Ольга) |
| Tier | 1 | 1 (досудебное) + эскалация |
| Ценность высоких ставок | нейтрально | **повышает** ценность тёплого лида для адвоката |

## 4. Цена входа (почему дорого)

- Другой домен права (админ/военное), другой валидатор-партнёр.
- Обязательная честная эскалация и аккуратные дисклеймеры (юридическая ответственность выше).
- Риск репутации при overreach: если бот сгенерирует «уверенный» документ по проигрышному делу — вред человеку и бренду.

## 6. Reserv+ изменил картину: государство забрало простые отсрочки

Ключевой апдейт, переписывающий нишу: **простые отсрочки автоматизированы государством бесплатно.** 🟡
- **333 тыс.** отсрочек оформлено через Reserv+; **~80%** отсрочек можно оформить в приложении.
- **С 1 ноября 2025** ТЦК и СП **больше не принимают** заявления об отсрочке от граждан — только Reserv+/ЦНАП.
- **Авто-продление** (без заявления) для оснований, подтверждаемых в реестрах: инвалидность, временно непригодные, родители ребёнка с инвалидностью и др.
- Закон **№ 4210-IX** (февраль 2025) добавил основания: кибербезопасность, оборонпром, критическая инфраструктура.
- Бумажная справка с печатью больше не нужна — электронный военно-учётный документ в Reserv+.

**Стратегическое следствие:** однозначные основания → Reserv+ делает их сам, бесплатно. **Наше
адресуемое пространство сужается до того, что государство НЕ закрывает: спорные / отклонённые
случаи, обжалование ТЦК/ВЛК, админпозовы.** А это почти целиком Tier-3 (юрист), не авто-генерация.

## 7. Матрица безопасности под-сегментов

| Под-сегмент | Кто закрывает сейчас | Наш режим |
|-------------|----------------------|-----------|
| Однозначная отсрочка (инвалидность, многодетность, бронь) | **Reserv+ авто/бесплатно** | ❌ не наша ниша |
| Отсрочка с неоднозначными основаниями (уход, учёба, толкование) | частично Reserv+/ЦНАП | 🟡 Tier-1 triage: помочь разобраться/собрать пакет |
| **Reserv+ отказал / неверный статус** | никто (человек растерян) | 🟢 **наш вход**: разбор оснований → тёплый лид юристу |
| Оскарження рішення ВЛК | юрист | 🔴 Tier-3 — только эскалация |
| Оскарження дій ТЦК / адмінпозов | юрист | 🔴 Tier-3 — только эскалация |

> Вывод жёстче, чем в Части 1: **безопасной авто-генерации почти не осталось** (Reserv+ съел простое).
> Продукт = **триаж + lead-gen для юриста-партнёра**, с минимумом автономных документов.

## 8. Поиск валидатора-партнёра (критерии)

- **Где искать:** профильные военно-правовые адвокаты (видны в Telegram/публикациях — Чумак і
  Партнери, Бачинський та партнери, asap-advokat и др.), военные комитеты адвокатских объединений,
  рекомендации.
- **Условия партнёрства:** комиссия за конвертированный лид; SLA ответа (часы, не дни — срочность);
  раздел ответственности; co-branding для доверия.
- **Критерий выбора:** реальная практика по ТЦК/ВЛК 2024–2026, а не «общая» практика.

## 9. Месседжи для военно-правовых Telegram-каналов

- Тон: **без ложной уверенности**, аккуратные дисклеймеры (ставки экзистенциальные).
- Входная точка — **отклонённые Reserv+ случаи** (там государство «не справилось», WTP максимальна):
  «Reserv+ отказал в отсрочке? Разберём основания и подключим военного юриста».
- НЕ обещать «выиграем суд»; обещать «разберём, есть ли основания, и не потеряете время».

## 10. Модель эскалации / комиссии

`Бесплатный триаж → квалификация (есть основания?) → тёплая передача юристу-партнёру → комиссия за
конвертированный лид.` Трекать конверсию triage→консультация→оплата; забенчмаркить размер комиссии
в военных делах (открытый вопрос из Части 1).

## 11. Комплаенс / ответственность

- Жёсткие дисклеймеры; **никаких автономных high-stakes документов**.
- Чувствительность данных (военно-учётные данные) → требования к хранению/защите выше; проверить
  на соответствие законодательству о персональных данных.
