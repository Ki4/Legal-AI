# Legal-AI — пітч для техліда (WTP-фокус)

> Дата: 2026-07-07. Аудиторія: техлід (потенційний технічний співзасновник),
> який приймає розмір ринку, але ставить головне питання — **чи готові платити**.
> Формат: self-contained HTML-дека `2026-07-07-techlead-pitch.html` (клон каркаса
> `2026-07-06-olga-presentation.html`). Це md-двійник = джерело контенту.
>
> **Тон — чесний за духом репо.** Не імітуємо доказ WTP. Показуємо: ринок
> реальний + PoC працює + рушій робить вертикалі дешевими → прямо називаємо
> відкрите питання WTP → даємо дешевий швидкий план його закрити з go/no-go →
> кличемо техліда со-власником валідації і закрити заглушку оплати.
>
> Статус фактів: ✅ лічильні (з коду / реєстрів) — обсяги справ, 2 live-послуги,
> детект зміни закону; 📋 гіпотези — ціни (₴349 / ₴300–800 / медпакети
> ₴1490–3490), конверсія, TAM у грошах.

## Слайд 1 — Титул
Legal-AI. Рушій, що виробляє українські **court-ready** документи там, де
безпечно, і чесно передає юристу там, де ризик. Не «ІІ-юрист». Продукт — це не
divorce чи alimony, а **машина, що виробляє послуги**.

## Слайд 2 — Проблема / JTBD
Люди платять за впевненість, а не за PDF.
- Типовий позов (розлучення, аліменти) = юрист ₴3 000–5 000 + ~2 тижні. 📋 (якорі конкурентів)
- Безкоштовні Дія/Е-суд є, але головний страх — **суд відмовить**, місяць втрачено.
- Тригер емоційний (партнер подав першим / перестали платити аліменти).
- Клієнт купує «перевірено, суд прийме».

## Слайд 3 — Що вже реально працює (PoC, не слайдвар) ✅
- 2 живі послуги у проді — розлучення + аліменти (`generation_mode='template'`).
- Наскрізний потік: TWA → форма → зашифровані `cases` → рендер court-ready PDF у
  приватний Storage → витяг-превʼю → екран оплати → signed URL 24 год.
- Агент «зміни законів» живий: авто-задетектив реальну зміну Сімейного кодексу →
  divorce+alimony на рецензію (сесія S79).
- AES-256-GCM шифрування PII; rate-limit 20/24год.
- ⚠️ Оплата = заглушка (навмисна межа PoC, слайд 7).

## Слайд 4 — Архітектурний важіль: послуга = дані, не код
- Один рушій рендерингу на всі послуги.
- «Послуга» = рядок у `services`: форма + шаблон + generation_mode + цитати + чек-лист.
- Додати послугу = описати дані, не програмувати.
- **Для техліда:** юніт-вартість нової вертикалі ≈ нуль → медична коштує стільки ж, скільки сімейна.

## Слайд 5 — Довіра = продукт (Human-in-the-Loop)
- ~95% детермінований шаблон + ІІ лише на відмінках ПІБ → нуль галюцинацій у даних.
- Publish-gate + рецензія зміни закону юристом.
- Badge «перевірено юристом» + чесний hand-off складного.
- Юридичний рів: DoNotPay → штраф FTC $193K за «robot lawyer»; HITL з 1-го дня.

## Слайд 6 — Ринок: один рушій → багато вертикалей
- **Сімейне ядро ✅:** 33 447 заяв на аліменти (2025); 38,7 тис. судових розлучень
  (H1 2025, ~75%); конкуренти беруть ₴199–5 000.
- **Медична вертикаль ✅ (розмір) / 📋 (гроші):** 37,6 тис. приватних ліцензіатів
  (ФОП + малі клініки) з реєстру МОЗ; дедлайн МОЗ 08.07.2026; порожня ніша між
  шаблоном ₴900 і юристом ₴3 000+.
- Той самий рушій виробляє обидві.

## Слайд 7 — Головне питання (чесно): чи заплатять саме нам? 📋
Ринок платить за **категорію** — доведено. Що заплатять **нам за self-service**
проти безкоштовних Дія/Е-суд — ні.
- CustDev: 0 з 8–12 інтервью.
- Платний smoke-тест — не запускався.
- Оплата в проді — заглушка, живих транзакцій нема.
→ Це єдиний блокер між «демо» і «першою гривнею». Кладу відкрито — бо саме на
цьому питанні є сенс вмикати техліда.

## Слайд 8 — План валідації WTP з go/no-go (дешево, швидко)
- **A · $0 (старт зараз):** 8–12 теплих CustDev через Олю. Питання (Mom Test):
  «коли востаннє платили за юрпослугу — за що і скільки?». Go: ≥50% мали проблему
  за 12 міс + реальні суми.
- **B · €300–500:** холодний Meta smoke-тест лендинга з реальною передоплатою.
  Go: CPL ≤ €3, лендинг→бот ≥15%, ≥ N передоплат.
- **C · перша ₴:** заглушку → Telegram Payments (1 послуги досить).
- Чому так: теплі канали завищують WTP → холодний тест спростовує.

## Слайд 9 — Прохання до техліда
Команда: Сергій (продукт/білд) · Оля (юр-експертиза, джерело правди) · **ти —
техлід** (активація «після підтвердженого PoC» — момент настав) · юристи за %.
1. Co-own валідацію WTP (A→B→C, пороги без самообману).
2. Побудувати payment-loop (закрити заглушку — Telegram Payments/ФОП).
3. Домовитись про формат участі й ролі (стартова розмова, не контракт).

## Слайд 10 — Наступні кроки + timeline
- **Цього тижня:** Сергій+Оля — 8–12 CustDev (крок A); ти — дивишся PoC зсередини + рішення про формат.
- **2–3 тижні:** лендинг + Telegram Payments; €300–500 smoke-тест (крок B).
- **Далі:** go → перша транзакція + 3-тя/4-та послуги; no-go → перепозиціонування за даними.
- Ціль зустрічі: рушій і ринок реальні, єдина діра WTP має дешевий план перевірки → домовляємось, чи заходиш зараз.
