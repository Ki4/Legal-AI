Особистий кабінет медичного ФОП — концепт-макет

Кликабельная демонстрация цикла «живих документів»: изменение закона → push → документы «потребують оновлення» → обновление в один тап → готовность восстановлена. Концепт для обсуждения, не финальный дизайн; данные вымышлены. Подробности: cabinet-vision.md.

🎬 Демо-сценарій (5 хвилин)

  1. 1Огляньте кабінет: Головна (кільце готовності), Документи, Люди (у «Ще»)
  2. 2Натисніть «Симулювати зміну закону» нижче — прилетить push, 2 документи стануть «потребує оновлення», кільце впаде
  3. 3Відкрийте стрічку Законодавство — картка зміни з поясненням юриста
  4. 4Відкрийте документ «потребує оновлення» → «Оновити документ» → нова версія за секунду
  5. 5Поверніться на Головну — кільце відновилося. Це і є цінність підписки
