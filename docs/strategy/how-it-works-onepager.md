# Як Legal AI робить документ — принципи (one-pager для демо)

> Для показу юристу-експерту. Простою мовою, без жаргону. Факти звірені з кодом і
> продом (аудит сесії 47, `docs/architecture/VERIFICATION-PROTOCOL.md`).

## 1. Шлях документа: форма → суд-готовий файл
Клієнт заповнює форму в Telegram → дані йдуть у рушій → **детермінований шаблон**
збирає документ → готовий файл повертається клієнту. **LLM не торкається** чисел,
дат, ПІБ, сум і структури — вони підставляються напряму з відповідей форми та з
вивірених юристом констант. Тому документ **не «вигадується»**.

## 2. Чому це надійно (анти-галюцинація)
- **Детермінізм.** Усі факти (суми, частки, дати, цитати статей, імена) — лише з
  форми + реєстру юридичних констант. Нуль «творчості» ІІ на даних.
- **Чек-лист-детектор.** На кожній генерації перевіряє, що в документі присутні
  обовʼязкові пункти (divorce — 5, alimony — 4). Пропуск → позначка юристу.
- Саме так divorce і alimony **вже працюють на проді**.

## 3. Як додається нова послуга — чотири яруси (A/B/C/D)
| Ярус | Що це | ІІ? |
|---|---|---|
| **A** | поля + обчислюване (підстановка) — більшість тексту | ні |
| **B** | блок юриста за правилом: юрист пише вивірений абзац, система обирає його за відповіддю клієнта | ні |
| **C** | ІІ-чернетка + ревʼю юриста — лише де аргумент **неможливо** перелічити наперед | так, під наглядом |
| **D** | ескалація до живого юриста (складний кейс → тёплий лід) | ні |

**Правило:** тиснемо максимум у **A/B** (детермінізм). **C** — крайній випадок,
**D** часто кращий за C (нуль ІІ-ризику + дохід з рефералу). Кожна нова послуга
розкладається по цих ярусах разом з юристом.

## 4. Що живе зараз / що далі
- **Зараз:** divorce, alimony — детермінований шаблон + чек-лист. В адмінці є
  **превʼю документа** (юрист бачить рівно те, що згенерується).
- **Найближче (до демо):** видача **файлом PDF/DOCX** замість публічної ссилки —
  приватніше (ПІБ/ІПН не у відкритому доступі).
- **Далі (липень+):** інструмент, де **юрист сам** заводить блоки A/B без
  розробника; перший пілот — **медичні документи** (детермінований пакет, є попит).

## Підсумок одним рядком
Сила системи — **не в «розумному ІІ», а в тому, що ІІ не дають помилитись на даних**:
детермінований шаблон + перевірки + людина там, де справді потрібне судження.
