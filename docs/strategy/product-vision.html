Хто, що, для кого і чому це працює

⚖️
Що це?
Telegram Mini App (TWA) — юридичний AI-асистент. Користувач заповнює розумну форму прямо в Telegram, AI генерує готовий юридичний документ і надсилає посилання на Google Docs.
🎯
Для кого?
Українці, яким потрібна юридична допомога (розлучення, аліменти, ТЦК, бізнес), але які не хочуть або не можуть платити юристу 3000–10 000 ₴ за документ.
💡
Ключова ідея
Замість "чату з AI" — структурована форма. Це дозволяє зібрати рівно ті дані, які потрібні для конкретного документу, і гарантовано отримати якісний результат.
💰
Бізнес-модель
Freemium: базовий документ безкоштовно, преміум версія (нотаріальна, з адвокатом, подача в суд) — за підписку або разову оплату. LTV клієнта зростає через довіру.
Як це працює

Повний шлях користувача

Від першого дотику до готового документу — кожен крок детально

1
🤖 Telegram Bot — точка входу
Telegram Bot
Користувач знаходить бота через пошук або рекламу. Надсилає /start. Бот показує меню із 5 послугами через inline-кнопки. При натисканні — відкривається Telegram Mini App з параметром ?service=divorce&uid=123
n8n Telegram Trigger inline keyboard webAppUrl
2
📋 Завантаження форми з Supabase
React TWA
Додаток зчитує ?service=slug з URL. Робить запит до Supabase: services таблиця → поле form_config (JSON). form_config описує всі таби, кроки, поля і умовну логіку (show_if). Поки завантажується — показує спіннер.
Supabase SELECT anon key form_config JSON RLS public read
3
✍️ Заповнення форми
Користувач
DynamicLegalFormBuilder рендерить форму по JSON-конфігу. Таби (до 4) → кроки (поля) → кнопка "Далі". Умовна логіка show_if приховує/показує поля залежно від попередніх відповідей. Прогрес-бар показує скільки залишилось. Всі відповіді зберігаються в об'єкті answers.
DynamicLegalFormBuilder show_if logic Framer Motion 8–30 полів
4
📤 Відправка відповідей в n8n
React TWA
POST на n8n webhook з трьома полями: { service_slug, user_id, answers }. Таймаут 15 секунд — якщо не відповіли але дані збережено, показуємо успіх. Бот закривається і показує SuccessScreen.
POST webhook 15s timeout AbortController
5
🗄️ Збереження кейсу в Supabase
n8n
n8n отримує дані → генерує _case_id (UUID) → INSERT в таблицю cases: user_id, service_slug, answers (JSONB), status="processing". Це гарантує що дані не загубляться навіть якщо наступні кроки впадуть.
Supabase INSERT cases table UUID case_id status: processing
6
🤖 AI генерує зміст документу
n8n + Groq
n8n відправляє answers + service_slug в Groq (llama-3.3-70b). Промпт: "ти юрист, склади текст позовної заяви в українському праві". Groq повертає готовий текст документу з усіма реквізитами. Час генерації: 3–8 секунд.
Groq API llama-3.3-70b structured prompt ~3–8s
7
📄 Створення Google Doc
n8n + Google
Копіює шаблон Google Doc у папку користувача (Drive API → Files.copy). Замінює плейсхолдер {{DOCUMENT_CONTENT}} на текст від Groq (Docs API → batchUpdate). Відкриває доступ "всі з посиланням" (Permissions.create). Авторизація через OAuth2 — документ зберігається в акаунті власника бота.
Google Drive API Google Docs API OAuth2 Files.copy batchUpdate
8
📩 Telegram: відправка посилання
n8n → User
n8n надсилає Telegram повідомлення користувачу (по user_id): "Ваша позовна заява готова! 📄" + посилання на Google Doc. Оновлює статус кейсу в Supabase: status="completed", doc_url=link. Весь процес від відправки форми: ~15–30 секунд.
sendMessage Supabase UPDATE ~15–30s total
