## Швидка довідка

### Судовий збір (2026)
- Розлучення: 0.4 прожиткового мінімуму = ~1 262 грн
- Аліменти: позивач звільнений від сплати (ст. 5 ЗУ "Про судовий збір")
- Поділ майна: 1% від ціни позову

### Підсудність
- За загальним правилом: за місцем реєстрації **відповідача**
- Виняток: якщо з позивачем діти — можна за місцем **позивача** (ст. 110 ЦПК)

### ІПН
- 10 цифр, починається з 1-3
- Якщо відмова від ІПН — вказується серія паспорта (2 літери + 6 цифр)

## ⚠️ Відомі обмеження тестування

### Playwright + кирилиця → знаки питання (`?????`)

**Симптом:** документ генерується коректно за структурою, але замість кириллічних символів — `?`.
Числа, пунктуація, дати — правильні. Шаблонний текст — правильний. Тільки введені дані — `?`.

**Причина:** Playwright на Windows емулює натискання клавіш (`keyboard.type`). Символи з кодом > 127 (кирилиця) не передаються через keyboard events — кожен символ стає `?` (ASCII 63).

**Перевірено (2026-05-13, сесія 10):** при прямому виклику через `test-webhook.mjs` той самий сценарій 2 (Коваленко, 2 діти, аліменти) генерує повністю коректний документ.

**Рішення для тестування:**
```bash
# Замість Playwright — відправляти дані напряму в n8n:
node scripts/test-webhook.mjs 2
# або з іншою URL (якщо VPS):
N8N_WEBHOOK_URL=https://n8n.yourdomain.com/webhook/form-submit node scripts/test-webhook.mjs 2
```

**Продакшн не зачіпає:** реальні користувачі вводять текст на телефоні в Telegram — там Unicode передається коректно.
