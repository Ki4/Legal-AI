# document-layout-preview — Validation

> Як доводимо, що зроблено. Детермінований код → **тести** (не evals — LLM тут немає). CI-гейт:
> червоне не мержиться. Критерій «готово» — нижче.

## Вимірюваний критерій «готово»
1. **Реєстр (G1)** — unit-тести зелені: усі канонічні блоки мають `label`+`help_text`+`color`;
   мапінг примітивів коректний; у v1-словнику немає widow/orphan.
2. **Розпізнавання (G2)** — на реальних divorce+alimony: 8 канонічних блоків знайдено; `appendices`+
   `signature` розпізнані як один `тримати-разом`-юніт; нерозпізнане → `unknown` без падіння.
3. **Пагінація (G3)** — детерміновані тести на мок-висотах: keep-together не розривається;
   overflow-блок потрапляє у `overflow[]`; page-break-before форсує сторінку; багатосторінковий кейс.
4. **Компонент (G4, RTL)** — рендериться для обох послуг; легенда розкривається; **caveat «наближено»
   присутній** у DOM; overflow-попередження показується на форсованому довгому блоці.
5. **Інтеграція (G5)** — секція «Розкладка» доступна в service-mirror; UI-suite зелений; tsc clean;
   0 нових lint-помилок.

## Тест-матриця (за § requirements)

| Перевірка | Тип | Що доводить |
|---|---|---|
| Реєстр повний + мапінг | unit (vitest) | SSoT валідний, нема «мертвих» атрибутів |
| detectBlocks на divorce/alimony | unit (реюз goldens/sampleAnswers) | блоки знайдено, appendices+signature = юніт |
| detectBlocks fail-closed | unit | нерозпізнане → `unknown`, не падає |
| paginate: keep-together не різати | unit (мок-висоти) | головний інваріант цілісності |
| paginate: overflow-блок | unit | edge «блок вищий за сторінку» → у `overflow` |
| paginate: page-break-before | unit | форс нової сторінки |
| paginate: багатосторінковий | unit | коректне призначення сторінок |
| Компонент рендериться (divorce/alimony) | RTL | прев'ю не падає на реальних даних |
| Легенда розкривається | RTL | гайд присутній і керований |
| Caveat «наближено» у DOM | RTL | інваріант чесності fidelity |
| Overflow-попередження | RTL | юрист бачить межу рушія |

## Ручна верифікація (візуальна)
- Відкрити service-mirror → «Розкладка» для divorce (сценарій діти+аліменти): переконатися, що
  блок Додатки→підпис **не розривається** (їде разом на наступну сторінку, якщо не вміщається), межі
  A4 намальовані, легенда пояснює кольори, видно caveat «наближено».
- Порівняти з реальним згенерованим документом (Google Doc із live form-submit) — пагінація
  **наближена**, не байт-точна (очікувано; зафіксувати, що fidelity advisory).

## Поза-перевіркою (нагадування зі scope)
- НЕ перевіряємо редагування (його немає), БД-реєстр, точний PDF, зміни form-submit — усе поза скоупом.
