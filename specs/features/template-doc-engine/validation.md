# Template Document Engine — Validation (Tier 2)

**Slug:** `template-doc-engine` · DRAFT · парный к `requirements.md` / `plan.md`.

Критерий «готово» = **parity + автопроверки + подпись Ольги** (≥2 согласующихся свидетельства,
`docs/architecture/VERIFICATION-PROTOCOL.md`). Тег ставить только при invocation, не definition.

## Автоматические проверки (CI)

### Фаза A — ядро
- [ ] **Parity-diff:** движок на данных из `generate_alimony_document` → текст PDF нормализованно
      эквивалентен эталону MCP (допустимы улучшения: даты прописью вместо ISO). Тест хранит эталон-фикстуру.
- [ ] **Склонение = эталон** на 4 падежах: орудний чол., родовий чол., родовий жін. (прізвище стоїть),
      родовий дитини. (Уже подтверждено в PoC 1-в-1 с Groq.)
- [ ] **Условные блоки:** `is_divorced=false` убирает абзац про розлучення; `defendant_employed=false`
      убирает блок про роботу. Проверка присутствия/отсутствия в PDF-тексте.
- [ ] **Плейсхолдеров нет:** в готовом PDF отсутствуют `{{` и `{%`.
- [ ] **Подпись не разорвана:** тест пагинации через Gotenberg — блок підпису на одной странице
      при свипе N (порт теста `sigtest/run_gotenberg.py`).
- [ ] **Preflight:** отсутствующее обязательное поле → явная ошибка, не тихий пропуск (StrictUndefined-эквивалент).

### Фаза B — авторство
- [ ] Разметка полей на алиментном docx → авто-выведенная схема содержит все ожидаемые поля.
- [ ] AI-предложение условия для блока даёт валидное выражение из существующих полей.
- [ ] Шаблон, собранный юристом в панели, на тех же данных даёт PDF, эквивалентный Фазе A.

### Фаза C — MCP
- [ ] `generate_document('alimony', data)` через MCP → PDF идентичен прямому вызову движка.
- [ ] Watermark «ЧЕРНЕТКА» присутствует; warnings/flags склонения возвращаются наверх.

### Склонение — HITL-каскад
- [ ] Известная фамилия из библиотеки → берётся оттуда, LLM не вызывается.
- [ ] Редкая фамилия (нет в pymorphy) → вызывается LLM-фолбэк.
- [ ] LLM неуверен → флаг в списке + инлайн-маркер; генерация НЕ падает тихо.
- [ ] Подтверждение Ольги пополняет библиотеку → повторный прогон не флагует.

## Человеческая приёмка

- [ ] Ольга открывает 1 реальный сгенерированный алиментный документ и подтверждает «court-ready».
- [ ] Ольга проверяет, что все спорные склонения были ей показаны (ни одного тихого).

## Команды проверки

- `apps/doc-engine`: `pytest` (parity, склонение, условия, preflight, пагинация).
- `apps/mcp-server`: существующие `vitest` parity-тесты + новый для generic generate_document.
- Пагинация: прогон `run_gotenberg.py`-подобного теста в CI с поднятым Gotenberg-контейнером.

## Регресс-защита

- Parity-фикстура эталона MCP закоммичена → любая правка движка, ломающая эквивалентность, красит CI.
- Тест пагинации в CI → правки шаблона, ломающие `keep_with_next`, ловятся.
