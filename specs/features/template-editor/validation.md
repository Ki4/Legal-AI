# template-editor — Validation

> Як доводимо, що зроблено правильно. Критерій «готово» (interview Q9): **E2E «Ольга без SQL»
> зелений + живий демо-прогін із Сергієм**. Юніт-тести — фоном.

## Сесія 1 (ядро) — checklist

- [ ] `npm run test` — усі існуючі тести зелені + нові `templateGate.test.ts`, `serviceTemplate.test.ts`.
- [ ] `tsc -b` чистий, `npm run lint` чистий, `npm run build:admin` збирається.
- [ ] Parity-тести рушія (`n8n/templates/__tests__`) НЕ змінені й зелені (рушій не чіпали).
- [ ] Міграція 030 застосована локально Сергієм; verification-SQL з шапки міграції повертає очікуване.
- [ ] Ручний прогін (десктоп): відкрити послугу → вкладка «Шаблон» → змінити текст → «Зберегти
      чернетку» → у БД draft оновився, `document_template` НЕ змінився → прев'ю (обидва таби)
      показують чернетку → «Опублікувати» → рядок у `service_revisions` + `document_template` = draft.
- [ ] Негативний прогін: зіпсувати `{{#if` → «Опублікувати» заблоковано, укр. повідомлення;
      «Зберегти чернетку» при цьому ПРАЦЮЄ.
- [ ] Мобільна ширина: редагування недоступне, прев'ю + підказка «зайдіть з комп'ютера».

## Юніт-інваріанти (vitest)

1. `validateTemplate`: валідний шаблон → ok; незакритий `{{#if}}`/`{{#each}}`, кривий вираз → ok:false,
   message починається з «Помилка в шаблоні».
2. `unknownVariables`: form-поля і ENGINE_COMPUTED_FIELDS не флажаться; вигадане `{{qwerty}}`
   флажиться; `{{formatDate marriage_date}}`, `{{!style: right}}`, `{{#if x}}`, `{{@index1}}`,
   `{{this.name}}` — не флажаться як невідомі змінні.
3. `publishTemplate`: кривий шаблон → жодного insert/update; валідний → спершу snapshot-insert,
   потім update document_template (порядок перевіряється моком).

## E2E «Ольга без SQL» (Playwright; скелет у сесії 1, повний — фінал сесії 2)

Сценарій: логін в адмінку → послуга divorce → вкладка «Шаблон» → кнопкою «Праворуч» вирівняти дату →
кнопкою «З нової сторінки» помітити «Додатки:» → таб «Розкладка» показує обидва ефекти → «Опублікувати»
→ draft == published; повторно: зламати тег → публікація заблокована з укр. повідомленням.

## Приймання (кожна сесія)

- Живий демо-прогін із Сергієм (`npm run dev:admin`), обов'язково перед мержем у main.
- Сесія 3 додатково: sign-off Ольги на текст каркаса позовної заяви (юридичний зміст) ДО активації
  «Створити з каркаса» у проді.
